  • Three asks. The audience panel on the right and the asks themselves switch with the A key or the audience button.
  • IPTC, ask 1. IPTC already defines the fields. The gap is which ones survive to the viewer and how a person reads them, and Metawatch already measures survival. We bring the user research on the Digital Source Type labels, such as Edited using Generative AI.
  • IPTC, ask 3. IPTC lists software that supports its Photo Metadata, using data the vendor supplies. We ask to be listed, not certified. Conformance is a separate C2PA process and is not an ask here.
  • JPEG Trust, ask 1. Custom assertions are already possible in C2PA and in JPEG Trust, so the question is how a third-party report is shown, not whether it can be stored. A verified badge would invite the overreliance our own concern map warns about (Höltervennhoff et al., CHI 2026).
