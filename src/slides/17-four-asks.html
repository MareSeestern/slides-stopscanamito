  • Three asks. The audience panel on the right and the asks themselves switch with the A key or the audience button.
  • IPTC, ask 1. IPTC already defines the fields. The gap is which ones survive to the viewer and how a person reads them, and Metawatch already measures survival. We bring the user research on the Digital Source Type labels, such as Edited using Generative AI.
  • IPTC, ask 3. IPTC lists software that supports its Photo Metadata, using data the vendor supplies. We ask to be listed, not certified. Conformance is a separate C2PA process and is not an ask here.
  • JPEG Trust, ask 1. Test how people read a combined trust report. Demirtas et al. leave representing the indicator in JPEG Trust, and interpreting it through trust profiles and trust reports, for future work. We bring the user research. Say the 32.8% out-of-context result aloud, not on the slide. On their held-out set, 44 of 134 out-of-context cases, 32.8%. Media-context verification is the principal limitation, and that is a shared problem.
  • Custom assertions are already possible in C2PA and in JPEG Trust, so a report can be stored. A report should never be a verified badge. That would invite the overreliance our own concern map warns about (Höltervennhoff et al., CHI 2026).
  • JPEG Trust, ask 2. Test Amito against the JPEG Trust reference software, Part 4, which is at DIS. The checks should be expressed as trust indicators.
  • JPEG Trust, ask 3. Work with them on media-context checks, whether this image is from that event, time and place. That is the gap their 32.8% result names.
